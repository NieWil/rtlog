# Results from users' boards

Timing reports of the `timing` example (or the demo's `timing.md`) on real hardware, one file per board and rtlog version. To add yours, see [CONTRIBUTING.md](../CONTRIBUTING.md#share-your-boards-results).

W1 is `info!("x={} y={}", u32, u32)`; times are the median (p50) of per-batch means. A call's cost in cycles compares across machines; its time depends on the clock. Generated by `scripts/results.py`; do not edit by hand.
